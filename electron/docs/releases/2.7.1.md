Hallym MIPS 2.7.1, the MIPS simulator for Hallym University's computer architecture labs. Your programs assemble, run and export exactly as in 2.7.0 (the same SPIM core, the same `.hmx` images).

## Download (Windows 64-bit)

One file: **`HallymMIPS-2.7.1-win-x64-setup.exe`**. Run it: it installs for you only (no administrator rights) and adds *Hallym MIPS* to the Start menu. If you have an earlier 2.x, it replaces it; the previous edition, 1.x ("Hallym MIPS Simulator"), is left as it is.

The program is not code-signed, so **Windows shows a blue "Windows protected your PC" window the first time. Click *More info*, then *Run anyway*** (Korean Windows: *추가 정보* → *실행*). Step by step: [한국어](https://github.com/ars2323/hallym-mips-simulator/blob/main/docs/usage/usage.ko.md#windows-경고-창-넘기기) · [English](https://github.com/ars2323/hallym-mips-simulator/blob/main/docs/usage/usage.en.md#getting-past-the-windows-warning).

## What you will see that is different

- **The start screen's flight over the campus moves smoothly.** In 2.7.0 it stopped for a moment every half second (a tenth of a second, over and over). It now moves at every frame, and loops without a jump.
- Nothing else changes: your programs, and everything else in the window, work as in 2.7.0.

## Going back

If something is wrong with 2.7.1 on your PC, the earlier releases are still here:

- [2.7.0](https://github.com/ars2323/hallym-mips-simulator/releases/tag/v2.7.0): remove 2.7.1 first (Settings → Apps → Installed apps → *Hallym MIPS 2.7.1* → Uninstall), then install 2.7.0.
- [1.2.4](https://github.com/ars2323/hallym-mips-simulator/releases/tag/v1.2.4), the previous edition ("Hallym MIPS Simulator"): it installs beside 2.x, and the two do not touch each other.
