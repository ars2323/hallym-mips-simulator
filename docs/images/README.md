# Images of the Qt edition (1.x)

Everything in this folder is a record of **version 1.x, the Qt edition**, not
of the current version.

- `compare/*.png` (Korean labels) and `compare/en/*.png` (English): standard
  QtSpim 9.1.24 beside the Qt edition 1.2.3. They are the pictures of the 1.x
  user guide, [`../GUIDE-ko.md`](../GUIDE-ko.md) and [`../GUIDE.md`](../GUIDE.md),
  which `tools/make-guide-pdf.sh` turns into the PDFs of a 1.x release, and
  `tools/make-compare-images.py` makes them. They stay here, where 1.x's
  documents and tools expect them, so that 1.x can still be rebuilt and
  released as before.

The comparison for version 2.x (standard QtSpim beside the Electron edition)
is in [`../compare/`](../compare/).
