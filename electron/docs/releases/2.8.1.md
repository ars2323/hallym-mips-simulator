Hallym MIPS 2.8.1, the MIPS simulator for Hallym University's computer architecture labs. Your programs assemble, run and export exactly as in 2.8.0 (the same SPIM core, the same `.hmx` images).

## Download (Windows 64-bit)

One file: **`HallymMIPS-2.8.1-win-x64-setup.exe`**. Run it: it installs for you only (no administrator rights) and adds *Hallym MIPS* to the Start menu. If you have an earlier 2.x, it replaces it; the previous edition, 1.x ("Hallym MIPS Simulator"), is left as it is.

The program is not code-signed, so **Windows shows a blue "Windows protected your PC" window the first time. Click *More info*, then *Run anyway*** (Korean Windows: *추가 정보* → *실행*). Step by step: [한국어](https://github.com/ars2323/hallym-mips-simulator/blob/main/docs/usage/usage.ko.md#windows-경고-창-넘기기) · [English](https://github.com/ars2323/hallym-mips-simulator/blob/main/docs/usage/usage.en.md#getting-past-the-windows-warning).

## What you will see that is different

**The bar along the top is empty on the start screen.** The small mark in the corner and the four buttons at the right (tutorial, new file, open, settings) are gone from it: the card in the middle of the board already carries the mark, the program's name and the two ways in, so the board is no longer seen through a row of buttons for what the card offers. The bar comes back in full — mark, file name, toolbar and buttons — the moment a file is open.

One thing to know: **settings and About are reached from that bar, so on the start screen they are not there.** Open or start a file first (**바로 시작** → **새 파일**), and the buttons are at the top right as before.

Nothing else changes: the board, the card, the two choices and the tutorial are as in 2.8.0.

## Going back

If something is wrong with 2.8.1 on your PC, the earlier releases are still here:

- [2.8.0](https://github.com/ars2323/hallym-mips-simulator/releases/tag/v2.8.0): remove 2.8.1 first (Settings → Apps → Installed apps → *Hallym MIPS 2.8.1* → Uninstall), then install 2.8.0.
- [1.2.4](https://github.com/ars2323/hallym-mips-simulator/releases/tag/v1.2.4), the previous edition ("Hallym MIPS Simulator"): it installs beside 2.x, and the two do not touch each other.
