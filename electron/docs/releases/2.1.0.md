Hallym MIPS 2.1.0, the MIPS simulator for Hallym University's computer architecture labs. Your programs assemble and run exactly as in 2.0.0 (the same SPIM core); what changed is what you see.

## Download (Windows 64-bit)

One file: **`HallymMIPS-2.1.0-win-x64-setup.exe`**. Run it: it installs for you only (no administrator rights) and adds *Hallym MIPS* to the Start menu. If you have 2.0.0, it replaces it; the previous edition, 1.x ("Hallym MIPS Simulator"), is left as it is.

The program is not code-signed, so **Windows shows a blue "Windows protected your PC" window the first time. Click *More info*, then *Run anyway*** (Korean Windows: *추가 정보* → *실행*). Step by step: [한국어](https://github.com/ars2323/hallym-mips-simulator/blob/main/docs/usage/usage.ko.md#windows-경고-창-넘기기) · [English](https://github.com/ars2323/hallym-mips-simulator/blob/main/docs/usage/usage.en.md#getting-past-the-windows-warning).

## What you will see that is different

- **The window opens maximized**, every time.
- **More room for what you read.** On a wide screen the Editor keeps the width a line of code needs, and the rest goes to the Text list, which now shows each instruction's source line in full, and to the Inspector, which shows the 32 bits at full size.
- **Registers get more height.** The Console stays one line tall until your program prints something, then it grows. The border between Registers and the Console can be dragged, like the one between the Editor and the Run side, and a double click puts it back.
- **The tutorial speaks more plainly.** Each card is one short text. When a step asks you to do something (press F10, set a breakpoint, …), doing it takes you on; where there is something to see, the card first points at what just changed — a register, a value in memory, your program's output — and waits for **다음** (Next).
- **An error says what is wrong, then what to do.** The hint under it names common typos: `.global` → `.globl`, `.asciz` → `.asciiz`, `srll` → `srl`, `t0` → `$t0`, and it tells you when a register does not exist (`$s10`).
- **Messages in an empty panel are shorter, look the same everywhere and say what to do next**, for example in the Inspector before your first step, and on the Run side after you change your code.
- **Every question the program asks looks and works the same:** Haram, the window darkened behind it, Esc for the safe answer. A click outside it no longer makes it disappear.
- **While the tutorial or a question covers the window, the minimize, maximize and close buttons are dimmed with it** (they used to stay bright white).
- **One download:** the installer only; there is no zip any more.

## Going back

If something is wrong with 2.1.0 on your PC, the earlier releases are still here:

- [2.0.0](https://github.com/ars2323/hallym-mips-simulator/releases/tag/v2.0.0): remove 2.1.0 first (Settings → Apps → Installed apps → *Hallym MIPS 2.1.0* → Uninstall), then install 2.0.0.
- [1.2.4](https://github.com/ars2323/hallym-mips-simulator/releases/tag/v1.2.4), the previous edition ("Hallym MIPS Simulator"): it installs beside 2.x, and the two do not touch each other.
