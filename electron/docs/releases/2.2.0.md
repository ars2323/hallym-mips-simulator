Hallym MIPS 2.2.0, the MIPS simulator for Hallym University's computer architecture labs. Your programs assemble and run exactly as in 2.1.0 (the same SPIM core); what changed is what you see.

## Download (Windows 64-bit)

One file: **`HallymMIPS-2.2.0-win-x64-setup.exe`**. Run it: it installs for you only (no administrator rights) and adds *Hallym MIPS* to the Start menu. If you have 2.1.0 or 2.0.0, it replaces it; the previous edition, 1.x ("Hallym MIPS Simulator"), is left as it is.

The program is not code-signed, so **Windows shows a blue "Windows protected your PC" window the first time. Click *More info*, then *Run anyway*** (Korean Windows: *추가 정보* → *실행*). Step by step: [한국어](https://github.com/ars2323/hallym-mips-simulator/blob/main/docs/usage/usage.ko.md#windows-경고-창-넘기기) · [English](https://github.com/ars2323/hallym-mips-simulator/blob/main/docs/usage/usage.en.md#getting-past-the-windows-warning).

## What you will see that is different

- **The Assemble button is now called Save & Assemble**, because that is what it does, like Ctrl+S: it saves your file, then assembles it. For a new file it first asks where to save it. On the tutorial's example, which is never saved, it is still **Assemble**, and so it is in a narrow window (its tooltip still says Save & Assemble).
- **The yellow row in Registers says what it is by itself.** The note at the top of Registers ("노란 줄은 방금 바뀐 레지스터") is gone. In a wide window the row that just changed has a **Changed** tag at its end; at every width the status bar at the bottom names it in the same yellow (**방금 바뀜: `$t1`**), and after a run it names them all (three, then how many more).
- **After Ctrl+S the status bar says what happened to your file:** *저장됨* (saved), *예제라서 저장하지 않습니다* (the tutorial's example: not saved), or *저장하지 않음 (어셈블은 했습니다)* when you close the window that asks where to save.
- **Fixed:** if you closed that window for a new file, your program was assembled, but the window said the code had changed and hid Registers, and F10 asked where to save again. Now it shows your program, and F10 steps.
- **Fixed:** when you make the window wider (from half the screen to the whole of it, say), the bar at the top uses the room again instead of keeping its shortened buttons.

## Going back

If something is wrong with 2.2.0 on your PC, the earlier releases are still here:

- [2.1.0](https://github.com/ars2323/hallym-mips-simulator/releases/tag/v2.1.0): remove 2.2.0 first (Settings → Apps → Installed apps → *Hallym MIPS 2.2.0* → Uninstall), then install 2.1.0.
- [1.2.4](https://github.com/ars2323/hallym-mips-simulator/releases/tag/v1.2.4), the previous edition ("Hallym MIPS Simulator"): it installs beside 2.x, and the two do not touch each other.
