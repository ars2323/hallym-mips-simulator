Hallym MIPS 2.3.0, the MIPS simulator for Hallym University's computer architecture labs. Your programs assemble and run exactly as in 2.2.0 (the same SPIM core); what changed is what you see while you fix your code.

## Download (Windows 64-bit)

One file: **`HallymMIPS-2.3.0-win-x64-setup.exe`**. Run it: it installs for you only (no administrator rights) and adds *Hallym MIPS* to the Start menu. If you have an earlier 2.x, it replaces it; the previous edition, 1.x ("Hallym MIPS Simulator"), is left as it is.

The program is not code-signed, so **Windows shows a blue "Windows protected your PC" window the first time. Click *More info*, then *Run anyway*** (Korean Windows: *추가 정보* → *실행*). Step by step: [한국어](https://github.com/ars2323/hallym-mips-simulator/blob/main/docs/usage/usage.ko.md#windows-경고-창-넘기기) · [English](https://github.com/ars2323/hallym-mips-simulator/blob/main/docs/usage/usage.en.md#getting-past-the-windows-warning).

## What you will see that is different

- **Changing your code no longer hides Registers, Text, Data, the Inspector and the Console.** They go on showing the last program you assembled, with one line over them: *지금 보이는 것은 마지막으로 어셈블한 코드입니다* (what you see is the last assembled code). F10, F5 and Reset go on with that program until you press Ctrl+S again.
- **Errors appear right under the Editor**, in the new **Assemble** panel, next to the code you fix — no longer over the Run side. When there are none, the panel says when you assembled and how many instructions it made.
- **An assemble with errors keeps what you were looking at:** the registers, the memory and where the program had stopped stay as they were.
- **While your code differs from the assembled program, the Editor shows no blue line** (its line numbers are no longer the program's); the Text tab still shows where the program is. Breakpoints you set then take effect at the next Ctrl+S.
- **Reset starts the last assembled program again from the beginning.** It does not assemble your changed code; Ctrl+S does (and applies changed settings).
- **The tutorial keeps the whole panel it talks about bright**, with a blue box on what to look at, instead of lighting only that spot.
- The border between the Editor and the Assemble panel can be dragged; a double click puts it back.

## Going back

If something is wrong with 2.3.0 on your PC, the earlier releases are still here:

- [2.2.0](https://github.com/ars2323/hallym-mips-simulator/releases/tag/v2.2.0): remove 2.3.0 first (Settings → Apps → Installed apps → *Hallym MIPS 2.3.0* → Uninstall), then install 2.2.0.
- [1.2.4](https://github.com/ars2323/hallym-mips-simulator/releases/tag/v1.2.4), the previous edition ("Hallym MIPS Simulator"): it installs beside 2.x, and the two do not touch each other.
